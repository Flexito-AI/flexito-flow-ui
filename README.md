# flexito-flow-ui

Flexito brand skin for the OmniAI platform, delivered as one script.

- `fx-flow.js` is the full file. Paste its content into the platform's **HTML Script** add-on field. Only one copy may be loaded at a time.
- Version is printed in the console on load (`[fx] fx-flow v8.7 loaded`) and set on `<html data-fx="8.7">`.
- `fx=off` in the URL turns the whole layer off for that page.
- The allow-list at the top of the file (`window.__fxAllow`) limits the new look to given bot ids; empty means everywhere.

Current version: v8.7
